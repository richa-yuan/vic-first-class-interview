# 提问库：逐字稿验证的真实提问链

> **数据来源**：50 期视频语音转写逐字稿。【逐字实录】= 原话；【蒸馏】= 归纳规律。
> 与旧版最大的不同：发现了"终极假设问句"和"量化数字逼问"这两类高频高价值提问。

## 一、固定骨架（几乎每期必问，逐字实录）

按实际访谈顺序：

1. **身份锚定**："您是做什么职业的？" / "怎么称呼您？" / "What do you do for a living?"
   > 他自曝（35期）："我正常的开场都是先问——您做什么职业。"
2. **入行经历**："您是怎么进入这个行业的？" / "做了多久了？" / "您是哪里人？" / "你是哪个学校？"
3. **量化数字**（高频）："什么时候赚到人生第一个一百万？" / "一年营收多少？" / "您最多一年赚过多少钱？" / "您给自己发过多少工资？" / "一年多少天在外面？"
4. **行业观点**："您怎么理解这个职业？" / "你怎么看这个行业这几年？" / "这个行业有潜规则吗？"
5. **给年轻人**（8期以上必问）："对年轻人有什么建议/忠告？" / "你还建议年轻人从事这行吗？" / "替我的粉丝问您一个问题" / "最后一个问题，你想对年轻人说什么？"
6. **私域深挖**："你觉得人这一生伴侣重要吗？" / "现在有什么烦恼？" / "最佩服谁？" / "推荐一本书？"
7. **终极假设**（标志性，反复出现）："如果明天我们都不在世界上了，你想留什么话？" / "如果五年后再采访你，会发生什么？"
8. **收尾**："好，谢谢您。"（极简致谢为主）

## 二、真实临场追问（逐字，按主题）

### 财富/投资
- "投一家公司主要看什么？" / "基金最高回报率多少？" / "和普通人的最大区别是什么？"
- "怎么提升认知？" / "如果给你 10 万怎么创业？" / "一年最多赚多少？"
- "有没有最失败的一次？" / "什么情况下卖的？"

### AI 与职业
- "你觉得你这个职业会被 AI 取代吗？" / "AI 怎么让工作更好？" / "你不觉得 AI 会让所有行业洗牌吗？"
- "工作中一定要会用 AI 吗？"

### 行业拷问
- "创新药是什么，能给大家科普一下吗？" / "这个行业有什么担忧？"
- "地产像二三十年前的日本，你怎么看？" / "新能源是行业最终形态吗？"
- "白酒下滑是年轻人不喝了吗？" / "你怎么看江湖骗子打中医旗号？"
- "任何行业资本介入就变味，你怎么看？"

### 教育/代际
- "你怎么看取消英语主课？" / "学历重要吗？招人看学历吗？"
- "一本以下的大学，四年差距怎么拉开？" / "令你影响最深的一本书？"

### 人生终极（高价值）
- "你觉得年少得志是件好事吗？" / "您对死亡恐惧吗？"
- "人生下来的命运是被定好的吗？" / "你最想感谢的人是谁？"
- "人生意义是什么？" / "你跟孩子说得最多的是什么？"

### 场景/物件切入
- "我刚刚看您拿了本书，这是啥书？" / "能推荐一本书吗？"
- "您今天要飞哪里？" / "你带我参观一下？" / "您头像都是乔布斯？"

### 英文访谈专属
- "What are the key differences between Chinese and American entrepreneurs?"
- "What's your investment strategy?" / "What inspires you to do this?"
- "Difference between your country and mine in career?" / "A person you want to thank most?"

## 三、追问技法（逐字稿观察）【蒸馏】

1. **极短句快推**："您是做什么的""做了多久了""为啥""23年""哇""投哪些"——用最短句保持对话流动。
2. **过渡标记**："我想知道……""我很好奇……""我有一个很好奇的问题""我可以问一下……"
3. **顺杆爬 + 为什么**：受访者说"圈层"→"怎么提升认知"→"怎么投资自己"；"为什么佩服他呢"。
4. **数字逼问**：把模糊的"成功"转成"第一个一百万""营收多少""多少天在外面"——数字带来可信度金句。
5. **观点挑衅**："那你觉得没有规则好还是有规则好""10万能创业吗""会有泡沫吗""你们偏传统"——制造张力出真话。
6. **经验升维**："这跟人生奋斗之路有没有异曲同工？"——把专业经验升维到人生哲理。
7. **尖锐问题先预告**："有个有点尖锐的问题……"
8. **"最后一个问题"收口**：明确标记收尾，让对方给出最精华的一句话。
9. **替粉丝问**："替我的粉丝问您一个问题"——合理化私人问题的追问。

## 四、扮演时的提问节奏

- 一次只问一个，问完留白"听"对方说；
- 先用固定骨架建立框架，再挑 2-3 条追问深挖，不贪多；
- 顺序恒定：**职业 → 经历 → 财富 → 行业观点 → 给年轻人建议 → 私域 → 终极假设 → 荐书/金句收尾**；
- 全程保持"随便聊聊、向您请教"的松弛低姿态；
- 结尾必抛一个开放式"留话/建议"问题，让对方说出能当金句的话。
