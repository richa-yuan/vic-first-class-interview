# 内容公式：选题、标题、开场与脚本结构

> 基于最近 50 期视频标题 + 语音转写逐字稿逆向工程。可信度：【蒸馏】= 从标题/逐字稿归纳；【逐字实录】= 转写稿原文。

## ⭐ 头号手法：金句前置钩子（逐字稿新发现）

精读逐字稿发现他最重要的剪辑手法：**把受访者最炸裂的一句金句剪到视频最开头（0-5秒），再倒叙回到采访现场**。这是爆款的核心结构，优先于一切标题技巧。

真实案例（片头前3句即金句，来自逐字稿）：
- "我们保持了 15 年投资失败率为 0 的纪录……"（33期）
- "你玩不过资本的啦，任何行业都一样，你只要资本介入就完了。"（43期）
- "中国还缺很多行业，没有人愿意去做。缺什么行业？"（09期）
- "人生下来的命运是被定好的吗？这个就是因果。"（16期）
- "热烈终会过期，稳定、靠谱、温柔、长久才是人生的顶配。"（46期）
- "真的要做财务自由的话，不可能靠出卖时间和劳动力。"（21期）

**脚本模板**：
```
[0-5s 钩子] 受访者金句/反常识断言（配人物特写或空镜）
[5-10s 场景] "我今天在头等舱偶遇了一位……"
[10s-主体] 倒叙展开完整访谈：职业→经历→观点→建议
[结尾] 金句旁白升华 or 极简"好，谢谢您"
```
金句来源见 `golden-quotes.md`，按8大主题分类，可直接取用。

## 一、选题矩阵（4 大内容线）

从 50 期统计看，内容配比大致为：

| 内容线 | 占比 | 说明 | 代表标题 |
|--------|------|------|---------|
| **头等舱偶遇访谈** | ~48% | 核心流量密码，场景化随机采访 | "坐飞机头等舱的人都是什么职业？" |
| **行业/商业探秘** | ~26% | 深挖单一行业运作逻辑 | "揭秘医药行业运作逻辑……药企真的躺着赚钱吗？" |
| **历史/人文/社会** | ~12% | 历史谜案、战争、工业老城 | "肯尼迪遇刺现场是什么样？" |
| **人生感悟/认知** | ~6% | 纯观点与哲理输出 | "人这一生，最好的顶配是陪伴" |
| 个人生活/其他 | ~8% | 备婚、婚礼、日常 | "《备婚日记》西装是男人最好的医美" |

**选题原则**：以"头等舱偶遇"为基本盘，用行业探秘和历史人文拉高信息密度，用个人生活建立真实人设。

## 二、标题公式（6 大模板）

### 公式 1：场景 + 身份 + 灵魂追问（王牌模板）
> `坐飞机头等舱的人都是什么职业？`
> `在杭州住2000平法式城堡是什么样的体验？`
- 结构：**具体场景/身份 + "都是什么职业/什么体验"**
- 要点：用"头等舱/城堡/F1包房"等高门槛场景制造好奇缺口。

### 公式 2：偶遇 + 身份 + 话题清单
> `偶遇一位哲学教授，我们从哲学思辨聊到了AI时代教育，中国真的没有哲学吗？`
> `头等舱偶遇95后信托律师，我们聊了企业家离婚、境外信托、税务……财富与经济的底层逻辑是什么？`
- 结构：**偶遇 + 具体身份 + "我们聊了A、B、C……以及X是什么？"**
- 要点：罗列多个话题制造"信息量很大"的预期，末尾用一个终极问题收口。

### 公式 3：反常识 + 灵魂反问（爆款钩子）
> `头等舱采访：AI最先淘汰中层？为什么他说中国根本不缺工作？`
> `别着急变现，为什么财富要到40岁才兑现？`
> `15年投资0失败的秘诀？为什么财富自由了还坚持工作？`
- 结构：**争议断言/数字 + "为什么……？"**
- 要点：前半句制造反差，后半句用"为什么"引导点击。

### 公式 4：数字 + 身份标签 + 价值承诺
> `200亿基金投资人，认知决定你的收入上限`
> `深耕物流行业23年，如何看待世界？`
> `28岁当上外企CEO是什么体验？`
- 结构：**量化标签（金额/年限/年龄）+ 身份 + 价值点**
- 要点：数字带来可信度与冲击力。

### 公式 5：行业拷问
> `揭秘医药行业运作逻辑，从临床试验到药品上市全解析。创新药研发到底有多难？药企真的躺着赚钱吗？`
> `新能源汽车不断洗牌，什么样的车企才能活过这一轮？`
> `白酒行业还有未来吗？`
- 结构：**揭秘/拷问 + "到底……？真的……吗？还有未来吗？"**

### 公式 6：金句式（人生感悟）
> `人这一生，最好的顶配是陪伴`
> `人生所有的痛苦来自于解释系统出问题`
- 结构：**一句通透/反常识的断言**，不设疑问，直接当金句传播。

## 三、开场白模板【蒸馏】

```
【场景锚定】我今天在头等舱/XX场合，偶遇了一位……
【身份破冰】您是做什么职业的？（直接、不绕弯）
【降低防备】我不是记者，就是好奇，随便聊几句。
【价值预告】很多人好奇这个行业/这个人群，今天正好问问本人。
```

要点：强调"偶遇/随机/无剧本"，用"随便聊聊"降低对方戒备，快速进入正题。

## 四、标准脚本结构（四段式）

```
1. 钩子（前5秒）：一句反常识结论 or 强身份反差画面
   → "坐头等舱的僧人，跟我聊了聊死亡。"

2. 场景 + 破冰（5-15秒）：交代偶遇场景，抛出第一个身份问题

3. 核心访谈（主体）：3板斧提问 + 分主题追问（见 question-bank.md）
   → 每问必挖到具体故事/数字/观点，不停留在客套

4. 金句收尾（最后10秒）：用受访者一句话或一句感悟收束，留白
   → "他说：人这一生，最好的顶配是陪伴。"
```

## 五、文案风格守则

- **口语短句**：像聊天记录，不要书面长段落；
- **先具体后抽象**：先说"一个95后信托律师"，再说"财富逻辑"；
- **反差制造好奇**：身份与话题的反差越大越好（僧人聊欲望、投资人聊投胎）；
- **信息密度**：一段话里塞进 2-3 个具体名词（职业、行业、数字），让观众觉得"有干货"；
- **克制煽情**：金句来自事实，不空喊；多用"他说""我发现"，少用"我们应该"。
